# NST 회의록

먼저 `nuua-context` 스킬의 쓰기 규칙을 따른다.

## 1. 지난 차수 찾기 (제목에 "N차"가 붙는 정례 회의면)
- CQL: `space = NST AND title ~ "<회의 이름>" ORDER BY created DESC` → 가장 최근 1건을 `markdown`으로 읽는다.
- 그 페이지의 `### 다음 액션` 항목을 이번 회의록 첫 섹션 **"N-1차 회의에서 수립한 다음 액션 점검"**의 체크 대상으로 옮긴다. 메모에 결과가 있으면 항목 아래에 붙이고, 없으면 "(경과 확인 필요)"로 둔다.

## 2. 형식 (팀에서 실제로 쓰는 모양)
제목: `YYYYMMDD 회의 제목` (정례면 끝에 `N차`). 날짜는 회의한 날.

```
- YYYY/MM/DD H:MMam~H:MMpm
- 참석: 이름 직함, …           ← 메모에 있는 그대로. 추측해서 채우지 않는다.

배경                            ← 첫 회의·주제 회의일 때만, 2~3줄

### N-1차 회의에서 수립한 다음 액션 점검   ← 정례 회의일 때만
- 항목 → 결과

### 주요 내용 (주제가 여럿이면 주제마다 ### 소제목)
- 논의를 질문/답 흐름 그대로 짧게. 결론이 난 건 "→ 확정", 안 난 건 "→ 미정(사유)"

### 결정 사항
- 회의에서 결정이라고 한 것만. 제안·의견은 여기 넣지 않는다.

### 다음 액션
- (담당 팀 또는 사람) 할 일 ← 기한
특기 사항                        ← 있을 때만
```

- 날짜는 `10/7`처럼, 사내 약어(우.카, 운, 기, 응 등)는 메모에 쓰인 그대로 둔다.
- Jira 키(OBT-1234 등)가 나오면 그대로 남긴다. 링크는 `https://nuuainc.atlassian.net/browse/<키>`.
- 메모가 녹음 받아쓰기라 말이 섞여 있으면, 말한 사람을 지어내지 말고 내용만 정리한다.

## 3. 저장
1. 정리한 회의록을 먼저 보여 주고 "NST에 새 페이지로 올릴까요?"라고 묻는다.
2. 승인되면 `createConfluencePage`(`spaceId: 15991115`(NST), `contentFormat: markdown`). 부모 페이지는 사용자가 말한 곳, 없으면 같은 정례 회의의 지난 차수와 같은 부모(`getConfluencePage` 결과의 parentId).
3. 이미 있는 회의록(남이 만든 "(예정)" 페이지 등)을 채워 달라고 하면 **덮어쓰지 말고** 붙여 넣을 글로 준다.
4. 다음 액션 중 Jira로 만들 게 보이면 `jira-request` 스킬로 이어서 제안만 한다.
